# Doomsday'e Kadar Marvel İzleme Sırası

*Avengers: Doomsday* (18 Aralık 2026) öncesinde hangi Marvel filmlerini ve dizilerini hangi sırayla izlemen gerektiğini gösteren statik site.

- Vizyon sırasına göre tam liste veya sadece önemli yapımları gösteren **kısa yol**
- İzlediklerini işaretleme ve ilerleme çubuğu (tarayıcıda saklanır)
- Disney+ dizileri ve bonus Fox X-Men filmleri için filtreler
- Vizyon tarihine geri sayım

## GitHub Pages ile yayınlama

1. Bu klasörü bir GitHub deposuna yükle.
2. Depoda **Settings → Pages** bölümüne git.
3. **Source** olarak *Deploy from a branch* seç, branch: `main`, klasör: `/ (root)` → **Save**.
4. Bir iki dakika sonra site `https://KULLANICI_ADI.github.io/DEPO_ADI/` adresinde yayında olur.

Hayran yapımı, resmî olmayan bir rehberdir. Marvel Studios veya Disney ile bağlantısı yoktur.

Afiş görselleri Wikipedia'daki film/dizi sayfalarından alınmıştır ve `posters/` klasöründe bulunur; telif hakları ilgili stüdyolara aittir.
